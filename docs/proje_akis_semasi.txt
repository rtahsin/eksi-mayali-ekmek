## 1. MİMARİ KATMANLAR
```
Kullanıcı Arayüzü (Next.js 16 App Router + React 19)
       ↕
Özel React Hook'ları (useCariler, useOrders, useProducts, useKurye)
       ↕
Supabase Realtime & PostgreSQL + Firebase Firestore / Functions
```

## 2. MODÜLLER VE İŞ AKIŞI
1. **Sipariş Akışı**: Müşteri siparişi (Online / WhatsApp Parse) → `/admin/siparisler` → Durum Güncellemeleri → Kurye Atama (`/admin/kurye`) → Canlı Takip (`/siparis-takip/[id]`).
2. **B2B Cari & Ön Muhasebe**: `/admin/cariler` → Fiş Kesme (`B2BSlipModal`) / Tahsilat (`B2BCollectionModal`) → Dijital Fiş (`/fis/[id]`) & Ekstre (`/ekstre/[id]`) → Excel/CSV İndirme.
3. **Üretim**: Günlük Siparişler → Otomatik Reçete Hesaplama (`/admin/uretim`) → Fırın Pişirme Partileri.
